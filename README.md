# Student-Management-System
Student Management System

About the Project

Student Management System is a simple web-based project developed to display and manage student information.

Features

- Student details form
- Enter student name
- Enter roll number
- Enter course name
- Display student details in a table
- Delete button in the table (UI only)

Technologies Used

- HTML
- CSS

Project Objective

The main objective of this project is to create a simple and user-friendly interface for managing student details.
